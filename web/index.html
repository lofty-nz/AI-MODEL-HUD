How it works

This page shows what the AI Model Monitor panel (aimon) shows, for both PCs at once, plus temperatures and the docs. aimon's WEB ↗ button opens it.

Each PC

  • A small program, AI Hub, runs on each PC on port 8090. The server's copy is the one to bookmark: 192.168.50.235:8090 (also server.local:8090 from the main PC).
  • When the main PC is off or asleep, its card says so and offers Wake, which sends a Wake-on-LAN signal from the server.
  • The top of each card shows CPU temperature and load, RAM and the system drive. Under it is one tile per graphics card: temperature with the last 5 minutes as a line, how busy it is, VRAM, power, fan, and which containers are using it.

Problems

  • Each PC checks itself every 30 seconds and lists anything that needs you at the top of its card, in red (broken) or amber (worth a look), with what to do. A red or amber button at the top of the page says how many there are; click it to jump to them. The browser tab title gets a ⚠ too.
  • It looks for: a graphics card that stopped responding (or NVIDIA driver errors), floods of PCIe errors, containers that keep restarting, are unhealthy, crashed or were killed for memory, bad lines in container logs (out of memory, too many open files, lost graphics card, disk full), a drive over 90% full, and a CPU or card at its slowdown temperature.
  • ⏻ Restart (next to the PC's uptime) restarts that PC after you type its name. It only shows on PCs whose AI Hub config has "allow_reboot": true and where sudo lets it run systemctl reboot without a password; for now that's the server. A card that has stopped responding gets a RESTART NOW button in its problem box too.
  • PC settings (on this tab) holds switches saved on the PC itself. Limit … to 2.5 GT/s caps a graphics card's slot at the slowest PCIe speed, for a card whose link keeps dropping out (the server's GTX 1650 in the lower slot). It's applied again every time AI Hub starts, so it lasts across restarts.
  • Restart … by itself restarts that PC when a graphics card stops responding, after it has been quiet (cards under 10% busy, CPU under 30%) for 3 minutes, or after 30 minutes whatever. It leaves a PC alone for 5 minutes after it starts and stops after 3 automatic restarts in a day, so a dead card can't cause a restart loop.
  • Fixed problems move to Earlier problems under the list for a week, so you can see what happened while you were away.

Models and containers

  • The rows work like aimon. START and STOP run docker start and docker stop. Under an Ollama container, START loads a model and keeps it loaded, and STOP unloads it.
  • ↻ restarts a running container. Unload all frees every loaded model on that PC and leaves the containers running.
  • Dots: green is running or loaded, amber is starting or stopping, grey is off, red means the last action failed (the reason shows under the name).
  • Numbers on the right are VRAM · RAM in GB.
  • A blue name opens that container's web page. this PC only means Docker only lets that PC itself open it, for example Strata's chat page on the main PC.

Docs

The Docs tab lists everything in ~/Documents/ai-docs on the server.

  • ＋ Add takes a PDF, Markdown (.md) or text file: drop it on the box (or anywhere on the Docs tab), or pick it. Paste text saves a typed or pasted block as a new Markdown or text doc. Up to 25 MB; a name that's taken gets "(2)" added, nothing is overwritten.
  • ✎ Details on an open doc changes its title, description, category (the group it's listed under; type a new one to make it), importance and tags.
  • Important docs show a red mark, Low ones grey. The first drop-down above the list shows only important or commented docs; a tag under it shows only docs with that tag.
  • Sort orders each category: newest first (the default; the date is when the file was added or last changed), oldest first, A–Z, or important first. Comments always show newest first.
  • 💬 Comments are notes on a doc, shown with who and when. The name comes from Your name below, or else the PC it was written on.
  • 🎤 next to a comment box (and 🎤 Speak it under Paste text) lets you talk instead of type: press it, talk, press it again to stop. The server's own Whisper (the one Open WebUI's voice typing uses) writes it out in a few seconds and adds it to the box, so you can fix it before pressing Add. Browsers only allow the mic on the https address (the "Away from home" AI Hub link); on the plain address it offers to switch.
  • You can still copy files into the folder by hand; titles, categories, tags and comments live in its index.json.

Who can open it

Only this PC, the home network and Tailscale devices. Anything else gets "Not allowed".
